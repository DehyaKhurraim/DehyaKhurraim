<summary><b>⚠️ Stats cards showing broken / "402" / sad-face errors?</b></summary>
<br/>

That's not a bug in this file — the shared public instance at `github-readme-stats.vercel.app` has been intermittently paused/overloaded (it serves badges for a huge share of GitHub profiles and regularly hits its free usage quota). The `github-readme-activity-graph` and `streak-stats` services can hit the same GitHub API rate limits. A few options:

1. **Wait and refresh** — these outages are often temporary; reloading the page after a bit sometimes resolves it.
2. **Self-host for reliability (recommended)** — takes about 5 minutes and gives you a dedicated instance:
   - Fork [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats) (and similarly [DenverCoder1/github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats) and [github-readme-activity-graph](https://github.com/Ashutosh00710/github-readme-activity-graph) if you want those reliable too)
   - Deploy each fork to your own free [Vercel](https://vercel.com) account (each repo has a one-click "Deploy" button in its README)
   - Add a GitHub personal access token as an environment variable in that Vercel project (steps are in each repo's README)
   - Replace `github-readme-stats.vercel.app` / `streak-stats.demolab.com` / etc. in this file with your own `*.vercel.app` domain
3. **Drop a card** — if you'd rather not maintain an extra deployment, any individual `<img>` block above (stats, streak, activity graph, trophies) can simply be deleted without breaking the rest of the layout.

</details>
